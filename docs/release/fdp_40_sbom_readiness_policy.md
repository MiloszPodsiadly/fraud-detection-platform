# FDP-40 SBOM Readiness Policy

FDP-40 requires SBOM readiness before production enablement. Repository dependency SBOMs are generated by CI from resolved Maven, npm, and Python dependency graphs.

This repository workflow does not generate a production image SBOM for a release image digest. Production enablement still requires an SBOM bound to the released image digest.

Required repository evidence:

- CycloneDX JSON SBOM for Maven resolved dependencies
- CycloneDX JSON SBOM for npm resolved dependencies
- CycloneDX JSON SBOM for Python resolved environment dependencies
- retained SBOM artifact
- build workflow and commit SHA linkage

Required production evidence:

- SPDX or CycloneDX SBOM for the release image digest
- retained SBOM artifact
- vulnerability review
- security owner approval
- build workflow and commit SHA linkage

SBOM readiness is not runtime correctness proof, external finality, production certification, or bank certification.
